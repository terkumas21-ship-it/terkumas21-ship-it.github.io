SOLOMON TERKUMA — PROFESSIONAL PORTFOLIO
=========================================

This is a static HTML/CSS/JavaScript portfolio website.

Included:
- Professional profile photo
- Email, phone, Instagram, Facebook and WhatsApp
- Responsive mobile navigation
- Research/project portfolio
- Custom 404 page
- robots.txt
- .nojekyll for simple GitHub Pages publishing

QUICK PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub account if needed.
2. Create a repository named: YOURUSERNAME.github.io
3. Upload all files in this folder to the repository root.
4. In Settings > Pages, select the main branch as the publishing source.
5. GitHub will publish the site at https://terkuma-ship-it.github.io
6. Changes can take a few minutes to appear.

CUSTOM DOMAIN
GitHub Pages supports custom domains. After publishing, configure the domain under
Settings > Pages > Custom domain and then configure DNS with your domain provider.

IMPORTANT
The website does not contain a fabricated CV. The "Request CV" action opens an email
so you can provide a real CV when you are ready.
